# Shotflow → 豆包（Chrome 插件）

把第 4 步分镜的提示词和参考图一键填进豆包网页版「新对话 → 视频创作」。**不调用付费 API**，用的是你自己的豆包免费额度。插件不会自动下载成片。

## 安装（约 1 分钟）

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序**
4. 选本仓库里的 `extension` 文件夹
5. 确认工具栏出现「Shotflow → 豆包」图标

改过插件代码后，必须在 `chrome://extensions` **重新加载**本扩展，再回 Shotflow 点发送。

## 使用

1. 先在 [豆包网页版](https://www.doubao.com/chat/) 登录一次
2. 打开 Shotflow（本机 `http://localhost:3002` 或云端），进入项目第 4 步
3. 点该镜 **一键发送到豆包**
4. 插件会打开对话页：点侧栏「新对话」→ 进入正中间下方的「视频创作」→ 用输入框左侧「+」按图一、图二…顺序一张张挂参考图 → 再把提示词贴进对话框
5. 确认后点发送；成片下载后再回传到 Shotflow 该镜

豆包每次点「+」只收一张图。插件按人手同样的顺序操作，等上一张缩略图出现再挂下一张。
