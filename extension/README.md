# Shotflow → 豆包（Chrome 插件）

把第 4 步分镜的提示词和参考图一键填进豆包网页版「生视频」。**不调用付费 API**，用的是你自己的豆包免费额度。插件不会自动下载成片。

## 安装（约 1 分钟）

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序**
4. 选本仓库里的 `extension` 文件夹
5. 确认工具栏出现「Shotflow → 豆包」图标

## 使用

1. 先在 [豆包网页版](https://www.doubao.com/chat/create-video) 登录一次
2. 打开 Shotflow（本机 `http://localhost:3002` 或云端），进入项目第 4 步
3. 点该镜 **一键发送到豆包**
4. 新标签会打开豆包生视频页：提示词写入输入框，参考图按图一 → 图十顺序挂上
5. 确认后生成；成片下载后再回传到 Shotflow 该镜

若豆包改版导致「生成视频」按钮没点到，提示词和参考图仍会填好，手动点一次即可。
